# Daily Digest 🗞️

**Daily Digest** — это автономный инструмент для сбора, фильтрации и суммаризации свежих новостей и научных статей из мира искусственного интеллекта и технологий.

Бот избавляет от необходимости вручную читать десятки сайтов и соцсетей: одной командой вы получаете единый готовый файл с главными событиями за сутки или любой другой период.

---

## Что именно делает бот?

1. **Собирает публикации** из проверенных источников:
   - **Научные препринты**: [arXiv](https://arxiv.org) (категории AI, NLP, CV, ML, Security).
   - **Трендовые статьи**: [Hugging Face Daily Papers](https://huggingface.co/papers).
   - **Блоги ключевых AI-лабораторий**: OpenAI, Google DeepMind, Hugging Face, Meta AI, Mistral AI.
   - **Соцсети**: аккаунты лабораторий и исследователей в X (Twitter) через RSSHub.
2. **Очищает текст от мусора**: вырезает баннеры, HTML-разметку, стили, скрипты и ссылки, оставляя чистый понятный сниппет до 1500 символов.
3. **Убирает дубликаты**: отсеивает повторные ссылки на одну и ту же статью.
4. **Расставляет приоритеты**:
   - 🚀 **Главные релизы и прорывы** (новые модели GPT, Claude, Gemini, Llama, Mistral) — всегда на первом месте.
   - 🔬 **Исследования и бенчмарки** — результаты тестов, новые датасеты и архитектуры.
   - 📰 **Общие новости и обновления** — прочие события индустрии.
5. **Делает выжимку через Mistral AI**: генерирует 2–3 ключевых тезиса по каждой новости. Если API-ключ не задан или нет связи, бот автоматически использует аккуратное текстовое превью без сбоев.
6. **Сохраняет готовый дайджест**: формирует красивый документ в формате **Markdown (`.md`)** или **Plain Text (`.txt`)** в папку `data/digests/`.

---

## Каким образом он работает?

Весь процесс полностью автоматизирован и проходит через последовательный пайплайн:

```
[Источники: arXiv / HF / RSS / X]
             │
             ▼
   1. Сетевой сборщик (с повторами при сбоях и обработкой лимитов 429)
             │
             ▼
   2. Очиститель текста (удаление HTML, скриптов, санитизация и обрезка)
             │
             ▼
   3. Фильтр временного окна (отсечение старых новостей старше N часов)
             │
             ▼
   4. Дедупликатор (исключение повторяющихся ссылок)
             │
             ▼
   5. Классификатор (определение важности по ключевым словам в заголовках)
             │
             ▼
   6. AI-Суммаризатор (генерация кратких тезисов через модель mistral-small)
             │
             ▼
   7. Форматтер и Экспортер (сборка Markdown/Text файла в data/digests/)
```

## Быстрый старт

### 1. Установка

Требуется **Python >= 3.14** и менеджер пакетов [uv](https://github.com/astral-sh/uv):

```bash
git clone https://github.com/your-username/Daily_Digest.git
cd Daily_Digest
uv sync
```

### 2. Настройка AI-суммаризации (опционально)

Создайте файл `.env` в корне проекта и добавьте ключ Mistral:

```env
MISTRAL_API_KEY=ваш_ключ_от_mistral_ai
```

> *Если ключ не указан, бот просто возьмет чистый фрагмент текста статьи, ничего не сломается.*

### 3. Запуск

```bash
# Базовый запуск (новости за последние 24 часа в формате Markdown):
uv run daily-digest

# Собрать новости за последние 3 дня (72 часа):
uv run daily-digest --hours 72

# Выгрузить в виде простого текста (.txt):
uv run daily-digest --format text

# Отключить вызовы нейросети:
uv run daily-digest --no-summary
```

Готовый файл появится в папке `data/digests/` с именем вида `digest_2026-10-11_1200.md`.

## Docker и интеграция с другими сервисами 🐳

Сервис полностью адаптирован для независимого развертывания и взаимодействия с другими контейнерами (например, с ботом `Utility_bot`):

### 1. Запуск через Docker Compose

В состав проекта входит готовая конфигурация [`docker/docker-compose.yml`](docker/docker-compose.yml), демонстрирующая запуск сервиса дайджеста и потребителя в единой пользовательской сети:

```bash
# 1. Скопируйте настройки окружения
cp docker/.env.example .env

# 2. Соберите образ
docker compose -f docker/docker-compose.yml build

# 3. Первый запуск (одноразовый): генерирует дайджест в shared volume и останавливается
docker compose -f docker/docker-compose.yml run --rm daily-digest

# 4. Запуск фонового планировщика (Ofelia) для ежедневного автозапуска:
docker compose -f docker/docker-compose.yml up -d scheduler
```

### 2. Архитектурные свойства интеграции (Межсервисный контракт)

1. **Сетевая открытость (0.0.0.0 и DNS)**:
   - Внутри контейнера сервис слушает `HOST=0.0.0.0` на порту `8000`.
   - В общей Docker-сети другие контейнеры обращаются к сервису по DNS-имени: `http://daily-digest:8000`.

2. **Протоколы взаимодействия**:
   - **Вариант А: Общий диск (Shared Volume)** ──► *Рекомендуемый быстрый старт (код бота менять не нужно)*:
     - Том `digests_data` монтируется в папку `/app/data/digests`.
     - Права доступа согласованы: сервис работает под пользователем `appuser` (`UID 1000`, `GID 1000`).
     - **Атомарная запись**: файл сначала пишется во временный `.{filename}.tmp`, после чего атомарно перемещается в финальный `.md`. Читающий бот никогда не получит наполовину сформированный дайджест.
     - Боту достаточно периодически проверять наличие готовых файлов в примонтированной папке.
   - **Вариант Б: Асинхронный HTTP API (REST & Webhook)**:
     - `GET /health` — проверка статуса сервиса и готовности Mistral AI.
     - `POST /generate` — асинхронный запрос на сборку дайджеста. Мгновенно возвращает `202 Accepted` и `task_id`.
     - `GET /tasks/{task_id}` — опрос статуса задачи (`pending`, `running`, `completed`, `failed`).
     - `webhook_url` — при передаче в теле запроса:
       ```json
       {
         "hours": 24,
         "webhook_url": "http://<bot-service-or-host>:8080/callback",
         "webhook_secret_token": "ваш_секретный_токен"
       }
       ```
       сервис сам отправит `POST` с готовым результатом и заголовком `X-Secret-Token`.
     - ⚠️ **Особенности интеграции с внешним ботом**:
       - Контейнер внешнего бота может подключиться к общей сети `daily_digest_network` (в compose-файле бота: `networks: daily_digest_network: external: true`) и обращаться к дайджесту по DNS `http://daily-digest:8000`.
       - Сервер мониторинга бота на порту `8080` обычно обрабатывает эндпоинты здоровья (`/health`, `/healthz`, `/live`, `/ping`). Для приема вебхуков в боте необходимо предусмотреть роут `POST /callback`.
       - **Безопасность**: так как порт `8080` бота проброшен наружу хоста, эндпоинт `/callback` на стороне бота обязан проверять заголовок `X-Secret-Token`, защищая канал от несанкционированных вызовов из интернета.
   - **Вариант В: On-Demand запуск через Docker CLI**:
     - Контейнер не висит в памяти постоянно, а запускается вызывающей стороной (например, ботом через `docker.sock`) по требованию:
       ```bash
       docker run --rm -v $(pwd)/data/digests:/app/data/digests daily-digest --hours 24
       ```
     - Возвращает чистые exit codes (`0` при успехе, `!= 0` при ошибке).

3. **Лимиты ресурсов (Resource Limits)**:
   - Для сервиса `daily-digest` в `docker-compose.yml` задан жесткий лимит оперативной памяти (`memory: 512M` / `mem_limit: 512m`), чтобы аномалии сторонних сайтов не приводили к утилизации всей памяти хоста.

4. **Stateless и отказоустойчивость**:
   - Любые оборванные временные файлы `.tmp` автоматически очищаются при рестарте сервиса.
   - Повторные запросы за один период времени не создают поврежденного состояния и дубликатов.

5. **Healthcheck и Readiness**:
   - Docker регулярно проверяет эндпоинт `/health` и выставляет контейнеру статус `healthy`.

6. **12-Factor App конфигурация**:
   - Все параметры связи задаются через `.env`:
     - `DIGEST_OUTPUT_DIR` / `BOT_DIGESTS_PATH` — путь к общей папке дайджестов.
     - `HOST` и `PORT` — сетевой интерфейс и порт.
     - `MISTRAL_API_KEY` — ключ нейросети.
     - `RSSHUB_BASE_URL` — адрес инстанса RSSHub.
