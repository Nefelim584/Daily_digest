# Daily Digest 🗞️

**Daily Digest** — это автономный инструмент для сбора, фильтрации и суммаризации свежих новостей и научных статей из мира искусственного интеллекта и технологий.

Бот избавляет от необходимости вручную читать десятки сайтов и соцсетей: одной командой вы получаете единый готовый файл с главными событиями за сутки или любой другой период.

---

## Что именно делает бот?

1. **Собирает публикации** из проверенных источников:
   - **Научные препринты**: [arXiv](https://arxiv.org) (категории AI, NLP, CV, ML, Security).
   - **Трендовые статьи**: [Hugging Face Daily Papers](https://huggingface.co/papers).
   - **Блоги ключевых AI-лабораторий**: OpenAI, Google DeepMind, Hugging Face, Meta AI, Mistral AI.
   - **Соцсети**: аккаунты лабораторий и исследователей в X (Twitter) через RSSHub.
2. **Очищает текст от мусора**: вырезает баннеры, HTML-разметку, стили, скрипты и ссылки, оставляя чистый понятный сниппет до 1500 символов.
3. **Убирает дубликаты**: отсеивает повторные ссылки на одну и ту же статью.
4. **Расставляет приоритеты**:
   - 🚀 **Главные релизы и прорывы** (новые модели GPT, Claude, Gemini, Llama, Mistral) — всегда на первом месте.
   - 🔬 **Исследования и бенчмарки** — результаты тестов, новые датасеты и архитектуры.
   - 📰 **Общие новости и обновления** — прочие события индустрии.
5. **Делает выжимку через Mistral AI**: генерирует 2–3 ключевых тезиса по каждой новости. Если API-ключ не задан или нет связи, бот автоматически использует аккуратное текстовое превью без сбоев.
6. **Сохраняет готовый дайджест**: формирует красивый документ в формате **Markdown (`.md`)** или **Plain Text (`.txt`)** в папку `data/digests/`.

---

## Каким образом он работает?

Весь процесс полностью автоматизирован и проходит через последовательный пайплайн:

```
[Источники: arXiv / HF / RSS / X]
             │
             ▼
   1. Сетевой сборщик (с повторами при сбоях и обработкой лимитов 429)
             │
             ▼
   2. Очиститель текста (удаление HTML, скриптов, санитизация и обрезка)
             │
             ▼
   3. Фильтр временного окна (отсечение старых новостей старше N часов)
             │
             ▼
   4. Дедупликатор (исключение повторяющихся ссылок)
             │
             ▼
   5. Классификатор (определение важности по ключевым словам в заголовках)
             │
             ▼
   6. AI-Суммаризатор (генерация кратких тезисов через модель mistral-small)
             │
             ▼
   7. Форматтер и Экспортер (сборка Markdown/Text файла в data/digests/)
```

## Быстрый старт

### 1. Установка

Требуется **Python >= 3.14** и менеджер пакетов [uv](https://github.com/astral-sh/uv):

```bash
git clone https://github.com/your-username/Daily_Digest.git
cd Daily_Digest
uv sync
```

### 2. Настройка AI-суммаризации (опционально)

Создайте файл `.env` в корне проекта и добавьте ключ Mistral:

```env
MISTRAL_API_KEY=ваш_ключ_от_mistral_ai
```

> *Если ключ не указан, бот просто возьмет чистый фрагмент текста статьи, ничего не сломается.*

### 3. Запуск

```bash
# Базовый запуск (новости за последние 24 часа в формате Markdown):
uv run daily-digest

# Собрать новости за последние 3 дня (72 часа):
uv run daily-digest --hours 72

# Выгрузить в виде простого текста (.txt):
uv run daily-digest --format text

# Отключить вызовы нейросети:
uv run daily-digest --no-summary
```

Готовый файл появится в папке `data/digests/` с именем вида `digest_2026-10-11_1200.md`.

## Настройка источников и правил

Все параметры настраиваются в одном месте — [`config/config.yaml`](config/config.yaml):
- Включение/отключение конкретных источников.
- Время выборки новостей по умолчанию.
- Регулярные выражения для приоритетов новостей.
- Лимиты символов и параметры модели Mistral AI.
